# Word Recall — демоверсия

Кликабельный HTML-прототип приложения для изучения английского.

**Открыть:** https://mikpmarket-jpg.github.io/word-recall-demo/

Можно посмотреть главную, каталоги, топики, чтение, аудио, карточки, цикл обучения и настройки.

Топики содержат подготовленные диалоги с переводами. Остальные разделы включают демонстрационные материалы и имитации. Озвучка топиков использует голос браузера/устройства, видео YouTube требует доступа к YouTube. Это демонстрация интерфейса, а не готовое мобильное приложение.

Прогресс хранится локально в браузере; синхронизации между устройствами нет.

## Публикация

GitHub Pages: ветка `main`, папка `/(root)`. Главная страница — `index.html`.
Файлы публикуются как готовый статический сайт; дополнительная сборка не требуется.
